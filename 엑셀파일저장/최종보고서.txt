1. 프로젝트 개요
--------------------------------------------------------------------------------
경기케어 직원 및 이용자에게 시설 아침·점심·저녁 식단을 스마트폰에서 손쉽게
확인할 수 있도록 제공하는 PWA(Progressive Web App) 기반 식단 알림 서비스입니다.

기존에는 엑셀·종이 메뉴표를 직접 확인해야 했던 불편함을 해소하고,
관리자가 엑셀 파일을 업로드하면 자동으로 메뉴가 갱신되어
별도 앱 설치 없이 홈화면에 아이콘을 추가하여 앱처럼 사용할 수 있습니다.


2. 개발 목표
--------------------------------------------------------------------------------
  - 아침 / 점심 / 저녁 식단을 날짜별로 조회
  - 관리자 인증(비밀번호) 후 엑셀(xlsx) 파일 업로드로 메뉴 등록
  - 메뉴 항목별 이모지 자동 매핑으로 시각적 가독성 향상
  - 스마트폰 홈화면 추가(PWA) 지원
  - 카카오톡 공유 시 미리보기(OG 이미지) 표시
  - GitHub Actions 자동화로 서버 없이도 메뉴 데이터 갱신

4. 주요 기능 목록
--------------------------------------------------------------------------------

  [사용자 기능]
  ① 오늘 날짜 자동 표시 및 현재 시간대 식사 자동 선택
     - 오전 7시 이전 → 아침 자동 선택
     - 오전 7시 ~ 12시 → 점심 자동 선택
     - 오후 12시 이후 → 저녁 자동 선택
  ② 날짜 캐러셀 네비게이터 (오늘 ~ 5일 후, 화살표 좌우 이동)
  ③ 아침 / 점심 / 저녁 탭 선택 → 해당 메뉴 카드 표시
  ④ 메뉴 항목별 이모지 자동 매핑 (50여 종 키워드 매핑)
  ⑤ GSAP 기반 부드러운 전환 애니메이션

  [관리자 기능]
  ① 하단 우측 🔒 버튼 → 비밀번호 4자리 입력(0203)
  ② 엑셀(.xlsx) 업로드 → 날짜/아침/점심/저녁 자동 파싱 → 저장
  ③ PDF 업로드 → 텍스트 추출 후 수동 편집 지원
  ④ 텍스트 직접 편집 (날짜·식사명: 메뉴 형식)
  ⑤ 전체 메뉴 초기화

  [PWA / 공유 기능]
  ① 홈화면 추가 아이콘 (경기케어 메뉴, 512×512 PNG)
  ② 오프라인 캐싱(localStorage 백업)
  ③ 카카오톡/SNS 공유 시 OG 이미지 미리보기
  ④ iOS Safari 상태바 투명 처리 (safe-area-inset)

6. GitHub Actions 자동화 구성
--------------------------------------------------------------------------------
  엑셀 파일(260411-0420(케어).xlsx 등)이 저장소에 푸시되면
  parse-menu.js가 실행되어 menu.json을 자동 생성·커밋합니다.

  동작 흐름:
    엑셀 파일 업로드(push) → GitHub Actions 트리거
    → Node.js + SheetJS로 엑셀 파싱
    → menu.json 생성 (날짜별 아침/점심/저녁 JSON)
    → 자동 커밋 & GitHub Pages 배포

  효과:
    - 관리자가 엑셀만 업로드하면 앱 메뉴 자동 갱신
    - 별도 서버 불필요 (완전 무료 운영)


7. 데이터 구조
--------------------------------------------------------------------------------
  menu.json 형식 예시:
  {
    "2026-04-18": {
      "아침": ["된장국", "쌀밥", "김치", "달걀프라이"],
      "점심": ["비빔밥", "미역국", "불고기", "깍두기"],
      "저녁": ["삼겹살", "쌈채소", "된장찌개", "공기밥"]
    }
  }

  데이터 우선순위:
    menu.json (서버 자동생성) > localStorage (관리자 수동 입력)
